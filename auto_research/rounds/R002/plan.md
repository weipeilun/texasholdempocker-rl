# R002 计划：让搜索目标"诚实"，并让价值学得动

## 这一轮要回答的问题

R001（学习率衰减 + 加强搜索）跑到 2.7 小时，学习率已降到 30%，held-out 价值 MSE 仍是 0.1665 → 0.1663、赢家命中 0.432 → 0.436，
基准对 lookahead 在噪声内持平。用户追问价值目标的设计与价值瓶颈对搜索的影响，诊断给出三个数字：

| 诊断（v4 latest） | 对 3×lookahead | 对 3×heuristic |
|---|---|---|
| 搜索 64 次（基准设置，Q 最小最大缩放） | 0.205 | 0.340 |
| 只用策略（1 次模拟） | 0.160 | — |
| **只用价值的一步贪心**（每个合法动作取走后局面的己方胜率，补牌抽 4 张取平均，终局用真实结果） | **0.050** | **0.155** |
| 搜索 64 次，评估时关掉缩放（网络未重训） | 0.240 | 0.295 |

价值网络连"走一步之后哪个局面更好"都排不对，比只看策略还差得多；而搜索把这种排序再经最小最大缩放放大成近似 one-hot 的策略目标
（目标熵 0.5–0.6）。本轮回答：把目标去噪、加强价值学习之后，价值是否开始能排序、强度是否越过平台。

## 机制（为什么这样改）

- 根节点的顺序减半里，一半候选动作只被访问 1 次，Q 就是一次 v_θ；完成后的 Q 在节点内按最小最大缩放到 [0, 1]，再乘
  (50 + 最大访问数) × 0.1（全量搜索约 11）。Q = 0.251 / 0.253 / 0.249 会变成 5.6 / 11.2 / 0 个 logit。
- 我们的 Q 本来就是 [0, 1] 的胜率份额，缩放是 mctx 为 MuZero 无界价值设计的；关掉后 σ = 11 × Q：差 0.03 只改约 0.3 个 logit，
  直接获胜的着法（Q 差约 0.7）仍有约 8 个 logit。价值不确定时目标贴近先验，确定时才变尖。
- 价值的梯度只占总损失的约 1/5（权重 0.25 × CE 1.22 对策略 CE 1.1），共享主干主要按策略学；样本 64% 在开局（结果几乎不可预测），终局只占约 8%。
- 纯自对弈学到的是"四个我对打时什么能赢"；对规则机器人的对局给出不同风格对手下的真实胜负。

## 判定

- **supported**：价值一步贪心对 3×lookahead 比起点高 ≥ 0.05；训练中基准对 3×lookahead 的最后 3 次均值比第 1 次高 ≥ 0.05；独立基准中最好检查点对 v4 latest（锚点）≥ 0.55。
- **refuted**：价值一步贪心与 held-out 价值指标都没有改善。
- **inconclusive**：其余。

## 风险

- 终局每步全量搜索增加约 25% 算力：预计约 4.5–5 局/秒。
- 去掉缩放后，价值差异小的局面里策略改进变弱：如果价值仍学不动，策略也会停在先验附近（这正是要区分的情况）。
- 机器人对局里模型座位的价值目标来自"对机器人"的胜负，与纯自对弈混在一个回放池里（只占 15%）。
