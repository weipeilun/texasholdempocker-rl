# R001 分析：学习率衰减 + 加强自对弈搜索

## 这轮要回答的问题

v4 的平台是恒定学习率的噪声地板，还是搜索太弱？两项改动（学习率 2e-4 → 4000 步 5e-5 的分段线性衰减；自对弈全量搜索 0.06 × 128 → 0.15 × 256、快速 16 → 24、样本 5 → 12 / 局）同时生效。

## 执行

- 2026-11-06 09:15 启动，12:18 提前停止（3.06 h，59 个 iteration，4153 训练步，4.9–5.9 局/秒）。学习率按计划从预热到 4.9e-5，实测与 lr_factor 一致（"确保生效"得到验证）。
- 提前停止的理由：2.7 h 的检查时价值指标仍不动，同时诊断显示价值网络连一步之后的局面都排不对（见下），本轮的两项改动都不针对这一点；继续跑 6 小时的期望信息量低。

## 结论

- **学习率衰减生效，但不是瓶颈**：学习率降到 25% 后，价值 MSE 与赢家命中在噪声内不变；对 heuristic 有约 +0.05 的小幅提升（0.34 → 0.39），对 lookahead 持平。
- **加强搜索没有可见收益**：目标熵 0.52–0.56（比 v4 更尖），KL 差距没有缩小；评估端加搜索次数同样无效。
- **瓶颈在价值**：价值网络无法给兄弟局面排序（一步贪心 0.05，远低于只用策略的 0.16），搜索的 Q 主要是噪声，Q 的最小最大缩放又把噪声放大成近似 one-hot 的策略目标。
- **补充（12:22）**：R001 latest 的价值一步贪心对 3×lookahead 为 **0.200**（v4 latest 0.050，同一批 50 副发牌、200 局，差约 5 个标准差）。
  学习率衰减显著改善了价值给兄弟局面排序的能力——这正是搜索需要的部分——而全局价值 MSE / 赢家命中几乎看不出来（它们被开局不可预测的结果主导）。
  但这一改善没有转化为搜索下对 lookahead 的强度（训练中基准持平；关缩放的评估下 R001 latest 0.145，v4 0.24），说明搜索目标与策略仍被别的因素限制
  （Q 缩放放大的目标噪声是首要嫌疑，R002 检验）。
- 判定 **inconclusive**：假设的判据（基准 vs lookahead +0.05、对起点 ≥ 0.55）未达到；但学习率衰减对价值排序能力有明显正作用，搜索加强的作用无法单独确认。
- 指标教训：全局价值 MSE 不足以判断价值是否可用于搜索，之后每轮都测"价值一步贪心"。
- **更正（2026-11-06 15:30）**：上面"补充"的结论作废。R001 自己的存档检查点在第 30 / 40 / 50 / 58 个 iteration 的价值一步贪心是
  0.12 / 0.055 / 0.16 / 0.20，R002 的四个检查点是 0.06–0.19，而这些检查点的全局价值 R² 几乎一样。0.05（v4）→ 0.20 是检查点之间的噪声，
  不能说明学习率衰减改善了价值排序。判定仍为 inconclusive。见 R002/analysis.md。
