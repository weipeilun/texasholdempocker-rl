# R006 计划：策略带教——lookahead 作老师

## 这一轮要回答的问题

R001–R005 对 3×lookahead 都停在 0.26–0.30。R005（观测版本 2）对 heuristic 到 0.47，对 R004 0.552，对 lookahead 仍是 0.28–0.295。

R005 的诊断（it50 固定权重，`auto_research/style_stats.py`、`rounds/R005/diag/`）给出了一个具体机制。

1. **加深搜索没用。** considered 8 + 256 次模拟：0.2975 / 0.5025（默认 0.2825 / 0.47）。
2. **风格完全不同。** 下表是对 3×heuristic、200 局的平均值（模型 = 只取先验最大的动作，不搜索，强度与搜索时一样）：

| 每局 | 模型 | lookahead |
|---|---|---|
| 胜率份额 | 0.45 | 0.75 |
| 买牌数（1 / 2 / 3 级） | 14.0（9.4 / 4.0 / 0.6） | 8.3（3.3 / 3.6 / 1.5） |
| 同色拿 2 个 | **0.005** | **4.24** |
| 预留 3 级牌 | 0.54 | 1.99 |
| 贵族 | 0.74 | 0.06 |
| 对手下回合能赢时：抢先预留那张牌 / 不理会 | 0.05 / 0.525 | 0.265 / 0.11 |

3. **先验塌缩。** 在 12 局 lookahead 自己对局的 1165 次决策上，模型与 lookahead 一致 29%：
   - 同色拿 2 个可走时，模型的先验总质量只有 0.3%；lookahead 选它的 99 次，模型平均把它排在第 12。
   - lookahead 选预留 3 级牌的 128 次，模型先验 0.6%，排第 9.5。
4. **机制。** Gumbel 的改进策略是 π' = softmax(logits + σ(q))，σ = (50 + max N)·0.1·q，不做 min-max 缩放。
   - 兄弟动作的 q 相差 0.05 时，σ 只差约 0.5 个 logit。
   - 塌缩动作的 logit 落后 5–6，搜索抬不起来；快速搜索只考虑 8 个动作，自对弈也几乎不走它们。
   - 于是这类动作永远得不到数据，自我强化。
5. **阶梯校准**（同样的发牌）：
   - lookahead 对 3×heuristic 0.7975；
   - heuristic 对 3×lookahead 0.115。
   - 模型对 lookahead 略强于 lookahead 自身，但完全不会利用弱对手。

本轮回答：把 lookahead 的动作混进策略目标，模型能否学会这些动作并越过平台；目标的其余 75% 仍是搜索的 π'，由强化学习决定保留多少。

## 改动（对照 R005）

| 内容 | R005 | R006 | 对应指标 |
|---|---|---|---|
| 策略目标 | π' | **(1 − 0.25)·π' + 0.25·e_t**，e_t 是 lookahead 在该局面会走的动作。只在模型座位的全量搜索样本上，配置 `policy_teacher: bot:lookahead`、`policy_teacher_weight: 0.25` | 日志 "policy teacher agrees with the search on X"（metrics teacher_agree，起点约 0.29） |
| 起点 | R004 latest 转版本 2 | **R005 latest**（第 56 个 iteration） | — |

其余相同：
- 观测版本 2；
- 50% 对局有 1–2 个机器人座位；
- TD(λ) 0.95；
- lr 5e-5，6000 步 ×0.5，12000 步 ×0.3；
- 全量搜索 256 次模拟、32 个动作，概率 0.15。

代码：`train_splendor.play_game_iter`（老师的走法种子 = derive_seed(局种子, SEED_BOT, 决策序号)，与机器人座位同源，不改变对局本身）。测试：`splendor/tests/test_training.PolicyTeacherTest`。

注意：held-out policy_ce 是对混合后的目标计算的，与之前各轮不可比；价值指标仍可比。

## 判据

- **supported**：最后的检查点同时满足
  - vs 3×lookahead ≥ 0.35；
  - vs 3×heuristic ≥ 0.55；
  - 对 R005 latest ≥ 0.55；
  - style_stats 中同色拿 2 / 预留 3 级牌的使用率明显上升。
- **refuted**：vs lookahead ≤ 0.29 且 vs heuristic ≤ 0.50。
- **风险**：模型变成 lookahead 的复制品（对 heuristic 升、对 lookahead 回到 0.25）。若出现，下一轮把 w 降到 0.1，或只在前若干 iteration 带教，同时加大 c_scale，让搜索自己保留这些动作。
