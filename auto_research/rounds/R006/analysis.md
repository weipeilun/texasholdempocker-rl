## 结论

1. 带教修复了先验塌缩，对 heuristic 从 0.4875 提到 0.5575（旧标准），各轮最高。旧标准下对 lookahead 也到了 0.3175，第一次明确越过 0.30。
2. 更重要的是机制：**4 人局里搜索的价值取决于对手模型**。
   - max^n 把对手当成"像我一样"的玩家，在自对弈中是对的，对规则机器人不对。
   - 模拟次数被对手节点的分支吃掉，到不了自己的下一回合。
   - 让对手走先验的 argmax 后，同一个网络对 lookahead 从 0.3175 提到 0.43（latest）。
3. 带教让先验接近 lookahead（老师一致率 0.445），所以先验是这些对手的好模型。prior 已接近准确对手模型的上限（0.3875 vs 0.4025）。
4. 注意：老师就是基准对手。对 heuristic（不是老师）同样 +0.11，说明不只是记住了 lookahead；达标时还要对没见过的对手复核。

## 判定

**inconclusive**（按 spec 的旧标准判据）：
- vs heuristic 0.5575 ≥ 0.55，满足；
- vs lookahead 0.3175 < 0.35，对 R005 0.531 < 0.55，不满足。

但部署搜索下 0.43 / 0.665，这是迄今最好的智能体（网络 + 搜索）。
