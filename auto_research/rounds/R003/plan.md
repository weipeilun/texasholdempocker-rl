# R003 计划：TD(λ) 价值目标 + 更低的学习率

## 这一轮要回答的问题

R002 跑了 3.05 小时（51 个 iteration）。它对 R001 latest 的直接对局胜率是 0.604，独立基准对 3×lookahead 0.205（R001 0.145），
对 heuristic 0.415；但训练中基准对 lookahead 在噪声内持平（0.198 → 0.233）。

结束时补测了多个检查点，发现之前用来选方向的"价值一步贪心"在同一轮的相邻检查点之间大幅跳动，而这些检查点的全局价值 R² 几乎一样：

| 检查点 | 价值一步贪心 vs 3×lookahead（200 局） |
|---|---|
| v4 latest | 0.05 |
| R001 第 30 / 40 / 50 / 58 个 iteration | 0.12 / 0.055 / 0.16 / 0.20（均值 0.13） |
| R002 第 20 / 40 / 约 48 / 50 个 iteration | 0.06 / 0.15 / 0.08 / 0.19（均值 0.12） |
| R002 第 30、40、48 个 iteration 的权重平均 | 0.125 |

按领先者分数分组时，R001 latest 与 R002 latest 在两轮数据上的每组价值 R² 相差不到 0.02。也就是说：

- R001 / R002 对"价值排序"的结论（"学习率衰减把它从 0.05 提到 0.20"）是检查点噪声，作废。
- 网络学到的是"整体上谁领先"，没有学到"兄弟局面之间谁更好"。后者的差异很小，在胜负目标的噪声里，权重的微小变化就会让它重新洗牌。
  搜索恰恰需要后者。

本轮回答：把价值目标换成低方差的 TD(λ) 回报、再降低学习率之后，价值的局部排序能否变得稳定并提高，并转化为搜索强度。

## 机制

- **价值目标**：原来是终局胜负 z，四人局约 100 步之后才揭晓。开局样本的 z 方差约 0.19，网络能解释的只有约 6%。
  TD(λ)：G_i = (1 − λ) V_{i+1} + λ G_{i+1}，最后一步的 G 是 z。V_{i+1} 取下一个经过搜索的决策（全量或快速搜索；机器人座位的步跳过）
  的搜索价值向量，即根节点上被选动作的平均回传值（四个座位都有）。
  λ = 0.95 时，开局样本的目标主要来自约 20 步（5 圈）之后各局面的搜索价值，z 的权重只有百分之几。目标方差小得多，而且
  "这一步的价值 ≈ 下一步搜索看到的价值"正是搜索所依赖的一致性。
- **学习率**：5e-5 起，6000 步降到 2.5e-5，12000 步降到 1.5e-5（R002 末段约 6.3e-5）。减小 SGD 噪声对细小差异的扰动。
- **样本分布**：R002 有人到 11 分后每步全量搜索，样本有 36% 来自 ≥ 11 分的局面（R001 8%），开局只剩 44%。
  本轮推后到 13 分。
- **起点**：R002 latest。它对 R001 直接对局 0.604，策略已经适应关缩放后的软目标。从 R001 起步会再经历一次策略重新适应。

## 测量（吸取本轮的教训）

- 价值一步贪心与策略一步贪心：每次用 100 副发牌（400 局；deals 7000–7099，包含之前的 50 副），
  并在多个存档检查点上测（第 10、20、30… 个 iteration），看均值与波动，不看单个检查点。
- 搜索 vs 只用策略：同一批发牌、同一模型，评估模拟次数 1 / 64 / 256（`benchmark_end_sims*.json`）。

## 判定

- **supported**：同时满足三条。
  - 最后 3 个存档检查点的价值一步贪心（vs 3×lookahead，400 局）均值 ≥ 0.20（R001、R002 各 4 个检查点的均值为 0.13 / 0.12）；
  - 训练中基准 vs 3×lookahead 最后 3 次均值比第 1 次高 ≥ 0.05；
  - 独立基准中最后的检查点对 R002 latest（锚点）≥ 0.55。
- **refuted**：价值一步贪心均值没有提高（< 0.15），而且 held-out 价值指标（对真实结果）不比 R002 好（value_mse 近 5 轮 ≥ 0.142）。
- **inconclusive**：其余情况。

## 风险

- 自举偏差：开局的目标几乎全部来自网络自己的（搜索）估值。如果中盘价值是错的，开局会学到同样的错。终局目标仍是 z，信息会逐步向前传。
- 被选动作的搜索价值对当前行动者偏乐观（取最大）。四个座位轮流行动，偏差在向量里大致抵消。
- 新的 held-out 价值指标（对 z）在本轮可能变差：网络学的是 TD 目标而不是 z。以价值一步贪心与基准为准。
