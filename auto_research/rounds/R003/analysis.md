# R003 分析：TD(λ) 价值目标 + 更低的学习率

## 这轮要回答的问题

把价值目标换成低方差的 TD(λ) 回报（λ 0.95，用之后各步的搜索价值自举）、学习率降到 5e-5 起、终局全量搜索推后到 13 分，
价值的局部排序能否稳定并提高，并转化为搜索强度。

## 执行

- 2026-11-06 15:35 启动，21:26 停止：5.85 h，105 个 iteration，7426 训练步，约 5.5 局/秒。lr 5e-5 → 2.26e-5。
- 停止方式的副作用：`loop.py stop` 把 SIGINT 发给整个进程组，对局进程先退出，主循环把这当成错误记了下来
  （"training stopped by an error"）。最后一个 checkpoint 是 21:19（第 104 个 iteration），没有受影响。
  R004 起 `loop.py stop` 先只向训练主进程发信号。
- 停止的理由：对机器人的独立基准从第 50 个 iteration 起停在 0.26–0.275，训练中基准最近 4 次在 0.23–0.24。

## 结论

- **强度**：
  - 前 50 个 iteration（约 2.7 h）对机器人提高约 0.05，之后持平。
  - 对上一轮模型（R002）的直接对局继续变强，最后 0.615。
  - 也就是说，在自对弈的分布里越来越强，但对规则机器人这种不同风格的对手没有继续进步。
- **价值**：
  - 对 TD 目标的拟合在改善；
  - 对真实结果的拟合只略有改善；
  - 价值一步贪心没有提高。
  - 判断价值有没有用，以独立基准为准，价值一步贪心只作诊断。
- **搜索**：评估时的所有设置都在 ±0.04 的噪声内。强度由网络（主要是策略）决定。
- **判定 inconclusive**：
  - (a) 价值一步贪心均值 ≥ 0.20：未达（0.116）；
  - (b) 训练中基准最后 3 次 ≥ 第 1 次 + 0.05：未达；
  - (c) 对 R002 latest ≥ 0.55：达到（0.615）。
- **下一步（R004）**：自对弈与对机器人的强度分化了，下一步让训练对手多样化。有机器人的对局从 15% 提到 50%，每局 1–2 个机器人座位。
