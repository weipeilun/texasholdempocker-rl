# R004 分析：对手多样化

## 这轮要回答的问题

R003 对自己的旧版本继续变强，对规则机器人却停在 0.26–0.295。把有机器人的自对弈对局从 15% 提到 50%、每局 1–2 个机器人座位之后，
对机器人的强度能否越过平台，同时不丢一般强度。

## 结论

- 对 heuristic 提高约 0.05（独立基准）到 0.1（训练中），对 lookahead 没有提高，对 R003 不丢强度（0.552）。
- 模型学会了对付较弱的一步贪心对手，没有学会对付 lookahead。lookahead 的优势来自它的局面评估：每张牌还差几颗宝石、几回合买到、离贵族多远、对手能否下回合赢。
  这些量要从原始字段做逐色截断求和才能得到，网络在五轮里都没有学出来。
- **判定 refuted**：vs lookahead 0.2525 < 0.31。
- 下一步（R005）：把这些派生量直接放进观测。
- 最好模型（先验 8）仍是 R003 latest：vs lookahead 0.295 与 R004 latest 的 0.2525 在噪声内，但按规则取对 lookahead 更高的那个。
  R004 latest 在对 heuristic（0.4525）和直接对局（0.552）上更强，是 R005 的起点。
