## 结论

1. **同设置续训仍然有效，但收益在递减**。部署搜索 vs lookahead：R007 it200 → R008 it90 +0.06，it90 → it190 +0.08，it190 → it280 +0.016（噪声内）；
   直接对局：0.59 → 0.60 → 0.55。大约 it200 之后接近平台。
2. 价值头仍在改善（value_ce 一直在降），但不再转化为自对弈或对机器人的强度：最后 50 个 iteration 没有一次晋升。
3. 模型已远强于带教老师（vs 3×lookahead 0.84，持平 0.25），老师一致率在下降。带教 w 0.25 让约 55% 的不一致样本的目标被拉向一个更弱玩家的动作，
   这是平台的候选原因之一 → R009 检验。
4. 对没见过的 lookahead 变体，份额与对 lookahead 本身同步上升（alt1 0.7125 → 0.84），强度不是对老师的特化。

## 判定

supported：R008 的检查点对 R007 latest 0.5903（it90，288 局）且 vs 3×lookahead 0.6975 → 0.84（it190）；之后进入平台（it249 / it280 对 it190 0.55 / 0.56，区间含 0.5）。
