# R009 计划：降低带教权重（0.25 → 0.1）

## 背景

- R008（同 R007 设置续训，300 个 iteration，5.73 h 实际训练）让部署搜索下的强度继续上升：
  - vs 3×lookahead：R007 it200 0.6975 → R008 it90 0.7562 → R008 it190 **0.84**（持平 0.25）；
  - vs heuristic 0.96，vs 没见过的 alt1 / alt2 0.84 / 0.7925。
- 但 R008 末段有平台迹象：
  - 对 best 的评估在 it249 之后不再晋升（it254–299 为 0.42–0.52）；
  - 训练中基准 vs lookahead（128 次，96 局）it219–254 均值约 0.79，it259–299 约 0.81，几乎不动；
  - held-out value_ce 仍在降（0.846 → 0.823）。
- 模型已远强于带教老师 lookahead。老师一致率（搜索的首选 = 老师的动作）从 0.468 降到 0.450。
  - 带教把每个记录样本的策略目标的 25% 放在老师的动作上：搜索与老师不一致的约 55% 样本上，目标被拉向一个更弱玩家的选择。
  - R006 引入带教是为了修复先验塌缩（同色拿 2 个、预留 3 级牌几乎为 0）。这些动作类现在已经稳定地出现在搜索中，可以用较小的权重维持。

## 假设

带教权重 0.25 → 0.1 后，策略目标更多地来自搜索本身，训练能越过 R008 末段的平台：
部署搜索下，R009 的检查点对 R008 的最好检查点 ≥ 0.55，且 vs 3×lookahead 不低于它 0.03 以上。

## 风险

- 网络先验也是搜索里的**对手模型**（opponent_policy prior）。带教让先验接近 lookahead，这正是对 lookahead 基准有利的；降低带教可能让对手模型对 lookahead 不那么准。
  所以同时看没见过的 alt1 / alt2：若 vs lookahead 降而 alt 不降，是对手模型的问题；若都降，是策略变差。
- 先验塌缩回来：用 style_stats.py 复查"同色拿 2 个"和"预留 3 级牌"的频率（与 R008 起点比较）。

## 判据（部署搜索：512 次、considered 8、prior；发牌 seed 5e9）

- supported：R009 的某个检查点（it100 之后，按训练中基准挑 1–2 个）对 R008 起点 ≥ 0.55，且 vs 3×lookahead ≥ 起点 − 0.03，alt1 / alt2 不低于起点 0.03 以上。
- refuted：对 R008 起点 < 0.50，或 vs lookahead 与 alt 都明显下降。
- 对照：R008 自身 it90 → it190 在 100 个 iteration 里 +0.08（对 it90 0.6042）。R009 要比"同设置继续训练"更好，才算带教权重的作用；
  如果只是持平，结论是 inconclusive（续训的收益在 R008 末段已经很小，持平也有信息量）。
- 若 R009 的检查点满足替换条件（对当前最终模型 ≥ 0.55 且 vs lookahead 不降，heuristic / alt1 / alt2 不降），更新 `models/splendor_final/`。
